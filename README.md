# Loksabha_Elections_Result_Analysis_2024(Interactive dashboard creayion using Power BI)
# Project Objective
## The Party members of Election Commission wants to create an lok-sabha elections result of 2024.So that the Party members will analyse and improve their statergy for the upcoming elections in next 5 years.
# Insights
## 1. Overall Election Results Overview:
   - Create a pie chart showing the distribution of seats among the leading parties.

## 2. Geographical Vote Distribution:
   - Use a map visualization to display the geographical distribution of leading parties across states, using latitude and longitude for accuracy.

## 3. Top Constituencies by Margin:
   - Develop a bar chart highlighting the top 10 constituencies with the highest winning margins.

## 4. Close Contests Analysis:
   - Create a line chart to show the constituencies with the narrowest winning margins, focusing on the competitive nature of the elections.

## 5. Leading vs. Trailing Candidates:
   - Present a scatter plot comparing the winning margins of leading and trailing candidates across different constituencies.

## 6. State-wise Winning Party Analysis:
   - Design a stacked bar chart to show the number of seats won by each party in different states.

## 7. Detailed Constituency Analysis:
   - Use a table visualization to list all constituencies along with their leading and trailing candidates, parties, and winning margins.

## 8. Map of Election Results:
   - Create a filled map that visually represents which party won in each constituency using color coding.

## 9. Regional Leading Candidates:
   - Show a bubble map with bubbles sized according to the winning margin, overlaid on the geographical map of constituencies.

## 10. Margin Distribution:
    - Use a histogram to display the distribution of winning margins across all constituencies.

## 11. Top Parties by State:
    - Create a heat map to show which parties are most dominant in different states.

## 12. Leading Candidate Analysis:
    - Develop a bar chart showing the number of constituencies won by the top 5 leading candidates.

## 13. Trailing Party Performance:
    - Use a line graph to show the performance of trailing parties in terms of margin lost in each state.

## 14. Constituency Performance Comparison:
    - Design a dual-axis chart comparing the leading and trailing candidates' vote margins in key constituencies.

## 15. State-Wise Detailed Results:
    - Develop a drill-down report that allows users to click on a state and see detailed election results for all constituencies within that state.
